# Таро ясно — 4.0.0

Бесплатный русскоязычный статический сайт: 78 карт, 13 раскладов, 9 статей. Без регистрации, платных толкований, npm-зависимостей и запросов к платным API.

- Сайт: https://tarot-online-b0zf.onrender.com/
- Репозиторий: https://github.com/3779008-boop/tarot-online
- Существующий Render Static Site: `srv-dblusulg1s2s73bitsng`.
- Сборка: `node build.mjs`; каталог публикации: `dist`.
- Публичный контакт: https://vk.com/club224684946.

Версия 4.0.0 содержит новую редактуру всех значений, отдельные советы для отношений и работы, фотографии для страниц раскладов и тематические переходы между материалами. Подробнее — в `RELEASE-NOTES.md`. Изменения в репозитории сами по себе не подтверждают публикацию версии.

## Локальная сборка

Нужен Node.js 22 или новее:

```sh
npm test
npm run build
```

Для production-метаданных:

```sh
SITE_URL=https://tarot-online-b0zf.onrender.com npm run build
```

`dist` создаётся заново и не хранится в Git. Сайт многостраничный: не добавляйте SPA-перенаправление всех адресов на главную.

Без `SITE_URL` или `RENDER_EXTERNAL_URL` страницы имеют `noindex`, а `robots.txt` запрещает обход. Production origin — HTTPS-адрес без пути. Он используется в canonical, Open Graph, Twitter, структурированных данных и sitemap.

## Редактура значений

Основные источники видимых текстов:

- `editorial/major-wands.json`: 22 Старших аркана и 14 карт Жезлов.
- `editorial/cups-swords-pentacles.json`: по 14 карт Кубков, Мечей и Пентаклей.

Каждый ID содержит `upright` и `reversed`. Для каждого положения обязательны девять непустых строк:

| Поле | Назначение |
| --- | --- |
| `general` | Общее значение |
| `love` | Отношения |
| `work` | Работа и дела |
| `advice` | Общий практический совет |
| `mood` | Настроение |
| `challenge` | Препятствие в общем вопросе или работе |
| `loveChallenge` | Препятствие в отношениях |
| `loveAdvice` | Шаг для отношений |
| `workAdvice` | Шаг для работы |

Сборка требует ровно 78 известных ID без повторов между файлами, два положения и все девять полей. Неизвестные поля, пустые строки, HTML, символ `|` и переносы внутри строк вызывают ошибку. Заменяются только тексты. `direction`, `tags` и `priority` сохраняются из исходных таблиц.

Исходная структура и семантика:

- `cards.txt`: имена, ID, тема, порядок и масть; прежние тексты оставлены для совместимости.
- `upright-contexts.txt`: исходные прямые значения по темам.
- `meanings.txt`: исходные перевёрнутые значения, направления и смысловые признаки.
- `priorities.txt`: акценты и критерии выбора.
- `obstacles.txt`: исходные нейтральные препятствия.

После редактуры `c.upright` и `c.reverse` соответствуют новым общим значениям; `c.love`, `c.work` и `c.advice` сохраняют прежнее назначение советов. Для нового кода используйте `c.meanings[orientation]`.

## Расклады, статьи и изображения

`spreads.json` содержит 13 раскладов: названия, вопросы, вводные тексты, позиции, роли и `photoAlt`. Существующие URL сохранены.

Для каждого ID нужны два локальных файла:

- `assets/spreads/{id}.webp`: 1200 × 675, основная иллюстрация и превью ссылки.
- `assets/spreads/{id}-480.webp`: 480 × 270, уменьшенная версия.

Сборка требует все 26 файлов. Карточки используют `srcset` и отложенную загрузку. Фото заголовка расклада загружается сразу. Для Open Graph / Twitter используется собственная обложка расклада, у остальных страниц — обложка карты дня.

Обложки оформляют страницы. Интерактивная колода и энциклопедия продолжают использовать 78 исторических изображений Райдера—Уэйта—Смит. Источники и контрольные суммы: `assets/cards/manifest.json` и `assets/cards/CREDITS.md`.

`articles.json` содержит девять статей и прямые тематические ссылки `spreadId` / `spreadLabel`. Сборка проверяет существование целевого расклада. Связанные расклады в `build.mjs` подобраны по теме.

## Движок и интерфейс

- `engine.mjs`: перемешивание, карта дня, чтение позиций, советы и сочетания.
- `app.mjs`: выбор карт, вывод результата, локальное сохранение, поиск и согласие на аналитику.
- `style.css`: светлая палитра, адаптивные карточки и компактные фотозаголовки.
- `build.mjs`: проверка данных, применение редактуры, HTML, изображения и SEO.
- `fixtures.mjs`, `test.mjs`: фиксированные примеры и технические проверки.

«Да или нет» учитывает направление первой карты, препятствие и совет. Перевёрнутая карта не меняет ответ автоматически на противоположный; категории не являются вероятностями. В отношениях различаются интерес, дистанция, готовность действовать и устойчивость. Для периодов и выбора учитываются отдельные позиции.

Толкования формируются по редакционным правилам в браузере. Сервис знает выбранную тему, но не получает мысленно заданный вопрос и не имеет доступа к чужим мыслям. Тесты проверяют работу сайта и ограничения движка, а не точность предсказания.

Карта дня хранится в этом браузере до смены локальной даты устройства. Очистка данных удаляет её. При запрете localStorage интерфейс показывает уведомление.

## Аналитика и контакты

`METRIKA_ID` необязателен. При наличии номера Метрика загружается только после согласия; Webvisor и clickmap отключены. `spread_start` и `spread_complete` передают ID расклада. Вызовы в коде не заменяют проверку счётчика и целей в кабинете.

`WEBMASTER_TOKEN` задаёт необязательный метатег проверки Яндекс Вебмастера.

Публичный контакт в футере, контактах и политике — подтверждённое сообщество ВКонтакте. `CONTACT_EMAIL` больше не используется; личная почта из профиля не публикуется.

РСЯ не подключена. Скрытый контейнер `data-ad-slot="after-reading"` сохранён для будущего согласованного подключения. Подготовленное место не означает одобрение рекламной площадки.

## Публикация и откат

Базовый SHA `main` до подготовки 4.0.0: `4a79e2dfe83725f2a852eb35e5650d288b7769f1`.

Перед публикацией проверьте актуальную вершину ветки, diff, тесты, production-сборку и отображение на телефоне и компьютере. Используйте существующий репозиторий и Render Static Site. Фактический deploy и его URL проверяются отдельно после публикации.

Для отката повторно разверните предыдущий успешный deploy в Render либо создайте обычный восстанавливающий коммит на основе базового SHA. Не теряйте параллельные изменения других участников и не переписывайте историю принудительно. ID карт и формат сохранённой карты дня не менялись.
